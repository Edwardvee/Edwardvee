# 🚀 Iván Quiroga - Front End Developer

## 👋 ¡Hola, mundo! Soy Iván, un apasionado del desarrollo web desde Argentina

Soy **Iván Quiroga**, un **Front End Developer** con base en **Argentina**, especializado en construir interfaces web modernas, responsivas y visualmente impactantes. Mi misión es transformar ideas en experiencias digitales fluidas usando **JavaScript**, **TypeScript**, **React**, y un toque de creatividad inspirado en la precisión de un anime bien animado. 🖥️✨

## 💻 Lo que hago

- **Desarrollo Front End**: Creo aplicaciones web dinámicas con **React**, **TypeScript**, **HTML5**, y **CSS3**, asegurando diseños pixel-perfect y experiencias de usuario épicas.
- **Tecnologías clave**: Domino **JavaScript**, **TypeScript**, **React**, y también tengo experiencia con **Python** y **C#** para proyectos versátiles.
- **Herramientas**: Git, Vite, Webpack, y un enfoque en código limpio y escalable.
- **Pasión**: Me inspiro en la estética y narrativa de los animes para darle un toque único a mis proyectos, manteniendo siempre un estándar profesional.
