## Proyectos destacados

Algunos repos que representan mejor lo que hago:

- [`CodeAlpha_NetworkSniffer`](https://github.com/Edwardvee/CodeAlpha_NetworkSniffer)  
  Sniffer de red para capturar y analizar tráfico. Lo uso para practicar protocolos, sockets y detección de patrones raros.

- [`Write-Ups-Phoenix`](https://github.com/Edwardvee/Write-Ups-Phoenix)  
  Colección de writeups de CTFs y labs. Me enfoco más en explicar cómo pensé el reto que en solo pegar comandos.

- [`programacion-redes`](https://github.com/Edwardvee/programacion-redes)  
  Ejercicios y pruebas de programación de redes. Sockets, clientes/servidores simples y pequeñas herramientas para entender mejor TCP/UDP.

- [`WindowsInternals`](https://github.com/Edwardvee/WindowsInternals)  
  Notas, pruebas y pequeños experimentos siguiendo material de Windows Internals. Más laboratorio que teoría.

- [`RE-MA-Roadmap`](https://github.com/Edwardvee/RE-MA-Roadmap)  
  Roadmap personal de reversing / malware analysis. Voy agregando apuntes, recursos y ejercicios a medida que aprendo.
